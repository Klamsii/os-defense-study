Команды для защиты

Шесть тем из практической части Assignment 8.

Примеры выполняй в своей учебной Linux-машине. Вместо user1 укажи своего пользователя. sudo запускает команду с правами администратора.

Скрытый файл

echo 'My note' > ~/.config_note
ls ~
ls -a ~
cat ~/.config_note

~ — домашняя папка. Точка в начале скрывает имя от обычного ls. -a показывает скрытые имена. > создаёт или перезаписывает файл, cat читает его.

Жёсткая и символическая ссылки

mkdir -p ~/links_demo
cd ~/links_demo
echo 'Hello' > original.txt
ln original.txt link_hard.txt
ln -s original.txt link_sym.txt
ls -li
echo 'New text' >> original.txt
cat link_hard.txt link_sym.txt
rm original.txt
cat link_hard.txt
cat link_sym.txt

ln цель имя — жёсткая ссылка, -s — символическая. -i показывает inode: у original и hard он одинаковый. >> дописывает текст. После удаления original hard работает, sym указывает на отсутствующий путь. В задании путь оригинала — /home/user1/original.txt.

Системные каталоги и типы файлов

ls -ld /dev /proc /tmp /var/log
ls -l /dev
ls -l /dev | grep '^b'
ls -l /dev | grep '^c'

/dev — устройства; /proc — виртуальные сведения о процессах и ядре; /tmp — временные файлы; /var/log — журналы. | передаёт вывод дальше. grep фильтрует строки; ^ — начало строки. b — блочное устройство, c — символьное, d — каталог, l — ссылка, - — обычный файл.

Временная папка только для себя

mkdir -p /tmp/test_session
touch /tmp/test_session/test.txt
chmod 700 /tmp/test_session
ls -ld /tmp/test_session

mkdir создаёт каталог, -p — также недостающих родителей. touch создаёт пустой файл или обновляет время. 700 = rwx------: доступ только владельцу, кроме привилегированных процессов. ls -ld проверяет сам каталог.

Общая папка со sticky bit

sudo mkdir -p /home/shared_secure
sudo chmod 1777 /home/shared_secure
ls -ld /home/shared_secure

Ожидаемые права: drwxrwxrwt. Все могут создавать файлы, но удалять чужие записи мешает sticky bit. Владелец каталога и root — исключения. Другой способ включить: sudo chmod +t /home/shared_secure; убрать: sudo chmod -t /home/shared_secure.

Setgid и чтение прав

sudo chgrp projectgroup /home/shared_secure
sudo chmod g+s /home/shared_secure
ls -ld /home/shared_secure

Группа projectgroup должна существовать. chgrp меняет группу каталога. g+s включает setgid: новые файлы наследуют группу каталога. Убрать — chmod g-s путь. u — владелец, g — группа, o — остальные; r=4, w=2, x=1. Для каталога x позволяет проходить к содержимому.

Необязательная часть: очистка через cron

Если cron установлен и служба запущена, открой crontab -e и добавь строку ниже. Она каждый день в 03:00 удаляет только файлы *.txt из твоей папки test_session. Перед настройкой проверь путь. Это пример расписания, а не обязательная часть задания.

0 3 * * * find /tmp/test_session -maxdepth 1 -type f -name '*.txt' -delete

Поля: минута, час, день месяца, месяц, день недели. Проверить расписание: crontab -l.
